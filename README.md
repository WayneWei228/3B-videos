# 3B Videos

Narrated teaching videos for University of Waterloo 3B courses. Each video has English subtitles and chapters.

## Watch online

**https://waynewei228.github.io/3B-videos/**

- Subtitles are on by default.
- Click a chapter to jump to it.
- Use the speed menu to play from 0.75× to 2×.
- The site remembers where you stopped in each video.

## Watch offline

1. Download a `.mp4` file and the `.srt` file with the same name. Put them in the same folder.
2. Open the MP4 in a player that reads subtitles, for example [VLC](https://www.videolan.org/) or [IINA](https://iina.io/).
3. The player loads the subtitles automatically, because both files have the same name.

## Files

- `<number> <title>.mp4`: the video (1080p, H.264).
- `<number> <title>.srt`: the English subtitles.
- The number shows the order. A letter after the number (for example `10a`, `10b`) means one topic in two parts.
